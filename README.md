# NPJ Practice

Practice planner for NPJ Volleyball. Plan timed practice blocks (1v1, 2v2, Queens, Scrimmage, Open, Water break), then run practice with a full-screen timer. Works offline on iPhone and iPad once added to the home screen.

Open https://jasonboylan.github.io/NPJ-Practice/ in Safari, tap Share, then Add to Home Screen.

`src.html` is the source; `index.html` is built from it.
